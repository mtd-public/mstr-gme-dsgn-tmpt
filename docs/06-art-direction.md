# 06 · Art direction: the six house styles

Everything in the org is **generated in code**: no hand-drawn bitmaps, no
downloaded meshes, no audio files. The only baked assets are gig-ambulance's
GLBs, and those are generated by Blender Python. Pick one style per game and
keep every element inside it.

## Cross-style rules (all six styles follow these)

- **Saturation is information.** The most saturated colours are reserved for
  danger, reward and the player. Decoration stays muted. (dive REVAMP, gig
  DESIGN §8, whip-dash "emissive budget: torches, relics, idol eyes; nothing
  else glows, so glow always means something".)
- **Allegiance reads before shape.** Player hardware is one family (blue steel,
  cream) and enemy hardware another (olive/rust, navy + red lamp). Player
  bullets are orange; enemy fire is red (dive-depths).
- **Silhouette test:** every actor must be identifiable as a black shape at
  40 px tall (whip-dash).
- **Readable at depth.** Darkness fades to a *coloured* twilight, never black.
  splashy-fish's abyss is purple; whip-dash fog is pale jungle haze. Dodgeable
  projectiles ignore fog (`fog: false`) so they read at any distance.
- **One palette table.** Every colour comes from one table (`PALETTE` in
  Blender `kit.py`, `PAL` in whip-dash, `PALETTE` in pixelArt, CSS tokens). No
  inline hex in builders.

## 1. Toy-ink pastel ("chunky toy diorama")

**Games:** gig-ambulance (origin), splashy-fish, space-lion, finger-skater, both starters.
**Look:** chunky bevelled, smooth-shaded toy shapes, oversized wheels, chibi
characters about 2.5 heads tall with dot eyes and blush. Thin **ink outlines**
(inverted hull) and **soft drop shadows** on a lavender or mint base. HUD is
cream cards with thick ink borders and hard shadows.

| Token | Hex | Use |
|---|---|---|
| ink | `#3b2e5a` | outlines, text, hard shadows |
| bg / lavender base | `#b9a3e8` / `#dccbf7` / `#c4b0ee` (3D background) | page, topbar, sky |
| cream | `#fffdf8` | cards, pills |
| purple | `#6e5ac8` | wordmark, headings, roofs |
| lilac | `#a58cf2` | secondary |
| yellow | `#ffd45e` | primary buttons, reward |
| gold | `#ffc53a` | coins |
| orange | `#ff9e4a` / accent `#e8792a` | wordmark accent |
| red | `#ee4b5e` (UI) / `#ff3d52` (lamps) | danger, medical |
| green | `#3ddc84` (UI) / `#56e27d` (beams) | pickup, good |
| mint grass | `#4cc79a` / `#3bb58a` | ground |
| pink | `#ff9fbd`; blush `#ff93a8` | cute accents |
| road | `#4b4959` + yellow lines | streets |

The full Blender palette (about 70 named materials with roughness and
emission) is `assets/models-3d/tools/blender/kit.py → PALETTE`. **Type:**
`'Trebuchet MS', 'Avenir Next', system-ui`, weight 800–900. **Rendering:**
`MeshStandardMaterial` at roughness 0.6, sRGB output, **no tone mapping** (so
pastels stay true; space-lion), hemisphere `#f1eaff/#5fbf97` at 1.9, warm sun
`#fff1dc` at 2.4, PCF soft shadows. Emissive only on windows, lamps, sirens,
beams and signs.

## 2. "Just under premium" flat low-poly (Kenney-adjacent)

**Game:** prof-whip-dash. Read `reference/prof-whip-dash/DESIGN.md §5` in full.

- Geometry: boxes, cylinders and icosahedra assembled in code. No meshes,
  textures or UVs.
- `MeshLambertMaterial({ flatShading: true })` from a cached `mat(color, opts)`
  factory, shared across every module.
- **ACES Filmic tone mapping at exposure 1.05.** "The single biggest step up from
  hobby WebGL."
- A single unlit gradient **sky dome** (one draw call, `fog: false`,
  `depthWrite: false`, `renderOrder: -1`). It's "the difference between a scene
  and a void above a road".
- `FogExp2` at 0.011 in a pale haze. It hides the recycle seam.
- Light rig: hemisphere `#BFD8E8/#4A3F2E` at 0.85, warm key 1.35 **from
  behind-left** (so threats cast shadows forward), cool rim 0.5.
- Post-processing is CSS layers only (vignette, grit). There are no GPU passes.
- Palette: Maya limestone `#E7DCC4/#D2C3A3`, cinnabar `#B5432E`, jade
  `#2FA98C`, turquoise `#3FBFD4`, obsidian `#241F2B`, gold `#F2C14E`, hazard
  `#E05437`, clear `#4FB286`. Egypt: sand `#DFC389`, lapis `#2B5F9E`,
  granite `#B07A5E`.
- **Speed read:** alternate two surface tones every 2.86 m, with a cadence marker
  (painted band, plank sleeper) at the same spacing in every biome. "Get this
  wrong and level 1 feels slower than level 2 for reasons the player cannot name."
- **Type:** Cinzel (display), Alfa Slab One (in-world shouts), Courier Prime (HUD
  readout), Public Sans (body). The earlier version used Anton + IBM Plex Mono.
- **Chrome:** one committed dark world (`--ink #101815`, `--panel #18221f`) so
  the shell matches the board instead of framing it in white.

## 3. In the Hunt pixel ("industrial arcade")

**Game:** dive-depths (`kits/pixel/pixelArt.in-the-hunt.ts`). Plan: `reference/dive-depths/REVAMP_IN_THE_HUNT.md`.

- Fixed internal resolution (256×512 for a 400×800 board). `imageSmoothingEnabled = false`. CSS upscales with `image-rendering: pixelated`.
- **Dark navy outlines, never pure black, never anti-aliased.**
- 2–3 stepped shading tones plus checker dither. **No gradients**, even for water
  transitions (stepped bands).
- Weathering: hashed moss and rust speckle. Seams and rivets.
- Explosions are the centrepiece: white-hot flash → orange fireball → rolling
  black smoke, 6/8/12 frames, often bigger than the thing that died.
- Palette: steel `#2c333a #454f58 #717f88 #c2ccd2`, olive `#232c1d #3a4728 #5c6a3a #93a05b`, rust `#3c2416 #6a3f20 #a8703a`, fire `#fff8d0 #ffd23e #ff8c1a #c93a12`, smoke `#121218 #26262e #454550`, warn `#d8302a #ff5a4a`, glow `#aef2e0 #ffe9a0`, outline `#0c1014`.
- Water zones every 5,000 leagues: Kelp Green → Abyssal Blue → Drowned Violet
  → Vent Crimson. Each is 4 bands from light to dark, with a cross-fade between.

## 4. Two-tone ("Downwell")

**Game:** dive-depths optional art mode (`kits/pixel/twoTone/`), shown in `assets/screenshots/dive-depths-two-tone/`.

- Sprites store **palette roles, not colours**: `CLEAR, INK(bg), FG, ACC, ACC2`.
  A palette is a 5-entry LUT, so a swap is instant and whole-game.
- Roles: bg (water, plus the ink every sprite is engraved with), fg (line art,
  player, text), accent (danger: every enemy is an accent mass engraved with
  bg), accent2 (water and tech: bubbles, glass, laser, pickups).
- Every sprite gets a **1 px bg moat** so it cuts cleanly into whatever it
  overlaps. Tone is hatching and ordered dither, never a blend.
- **No role is load-bearing on its own.** Palettes that collapse roles
  (Blackout, Silt) must still read by silhouette and engraving.
- 26 named palettes are in `palettes.ts` (Abyss `#000/#fff/#ff1f2d/#1f7bff`, Kelp, Sonar, DMG-01, V-Beam, Shallows, Sea Chart, …).
- Settings via `?art=twotone&palette=kelp&zones=1`. `C` / `Shift+C` cycles
  palettes. Zone-cycle mode steps to the next palette every zone.

## 5. Procedural 16-bit ("material-mask shader")

**Game:** sub-sinkers (`kits/pixel/sprites.material-mask-shader.js`, gallery page `reference/sub-sinkers/sprites.html`).

- Draw each sprite as **material ids** into a small `Buf` using ellipse, rect,
  poly and line primitives.
- Each material has a **palette ramp** (dark→light, 4–7 steps) and a shading
  model:
  - `cyl`: vertical runs, highlight at 28%
  - `hcyl`: horizontal runs
  - `sph`: light from the upper left
  - `vert`: top-lit
  - `flat`
- The renderer adds rim light (+0.1 on upper-left edges), rim shadow (−0.16 on
  lower-right edges), and **4×4 Bayer dither** between ramp steps. It then
  outlines with 1 px `#120a10`.
- Ramps: GOLD, RED, STEEL, DARK, GLASS, RGLOW, CGLOW, OLIVE, SAND, CRAB, PURP, ICE, TEAL, ORANGE, NAVY, BONE, PINK, GREEN, KELP, CORAL, FIRE, SMOKE, FOAM.
- Recolour per stage by swapping ramps in the level theme (`theme: { hull: P.TEAL, belly: P.ORANGE, … }`).
- **Type:** 'Press Start 2P' for the DOM menus, plus a 3×5 bitmap font in-canvas.

## 6. Hellish torch-lit ("Hellraiser dungeon")

**Game:** labyrinth-larry.

- Palette: ember `#ff6a1f`, blood `#b3100f`, bone `#f1e3c6`, ink `#120404`,
  panel `rgba(22,6,5,.88)`, gold text `#ffd27a`.
- Torch-lit tiles over a **self-lit lava sea**. The lava is a ShaderMaterial
  with layered value noise, domain-warped by time.
- A **light pool**: 6 real PointLights handed to the torches nearest the player
  each frame. Torch meshes glow without a light of their own.
- Chrome uses Impact / Arial Black with fire glow text-shadows, blood-red
  gradient buttons with a hard dark drop, and radial dark vignettes.

## Choosing a style

| If the game is… | Use |
|---|---|
| cute, casual, broad audience, phone-first | Toy-ink (1). Both starters ship it |
| a 3D runner or adventure that must look polished on low-end phones | Low-poly (2), with ACES + sky dome + fog |
| an arcade shooter with grit | In the Hunt pixel (3) or 16-bit shaded (5) |
| minimal, strong identity, cheap to author | Two-tone (4) |
| horror or edgy | Hellish (6) |

## Art bibles & preview pages (make one for every game)

- whip-dash `board.html`: a live art bible. The hero panel runs the real engine
  with an autopilot. Every other panel is a spinnable turntable sharing **one
  WebGL context** blitted into 2D canvases (phones cap GL contexts).
  `IntersectionObserver` pauses off-screen panels.
- dive-depths `asset-preview.html` / `assetPreview.ts`: an animated sprite
  roster, a live-fire demo scene, a palette table, a boss hangar and water-zone
  chips.
- dive-depths `two-tone.html`: live game, staged shots, sprite sheet.
  `scripts/render-two-tone-concepts.ts` renders PNG concept sheets in Node, using
  `scripts/png.ts` (a tiny PNG encoder).
- sub-sinkers `sprites.html`: every sprite on one page.
- gig-ambulance `assets/previews/sheet_*.png`: contact sheets rendered by Blender.
- whip-dash `camera.html`: camera presets plus sliders, printing the rig to paste.

Concepts go first, published as artifacts and linked from the design note. This
was the standard flow: "Design note (no engine changes yet)" → mock → build.
